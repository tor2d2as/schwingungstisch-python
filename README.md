# schwingungstisch-python
Dieses Python-Skript steuert einen Schwingungstisch. Dieser kann verwendet werden, um zu zeigen, wie wichtig die richtigen Einstellungen (z. B. Messbereich, Abtastrate, ...) bei einer Labormessung sind. Zusammen mit einem makroskopischen Beschleunigungssensor kann zudem die Funktionsweise eines Beschleunigungssensors demonstriert werden.
